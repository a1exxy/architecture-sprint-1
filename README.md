# Sprint_1

## Задание 1 - нужно разделить проект Mesto на несколько микрофронтендов

### Уровень 1. Проектирование
Выберите фреймворк для создания микрофронтендов:
Так как разделяется существующий проект, то хостовое приложение и все микрофронтенды будут написаны на react 17.
В данном случае рационально использовать Module Federation, т.к. это позволит уменьшить объем итогового приложения за счет использования общих библиотек (react, react-dom, ...)

Предпологается выделение следующих микрофронтендов c соответсвующими функциями:
- **auth**: 
  - страница логина 
  - страница регистрации 
  - попап ошибки логина
  - попап результата регистрации (InfoTooltip)
  - кнопка logout
- **profile**:
  - Отображение аватара
  - Отображение имени и описания пользователя
  - Попап изменения аватара
  - Попап изменения имяни и описания пользователя
- **places**:
  - отображение списка карточек
  - попап просмотра карточки
  - удаление карточки
  - добавление и удаление лайка на карточке
  - кнопка добавления места
  - попап добавления места

В **корневом** приложении остается следующий функционал:
- роутинг
- монтирование компонент МФ

**react context** содержащей информацию о пользователе необходим в:
- МФ profile - отображение информации о пользователе, заполенение попапов изменения информации. 
- МФ places - отображение поставленного лайка, отображение кнопки удаления на карточке.
Вышеуказанные МФ заполняют контекст о пользователе при монтировании путем посылаки api запроса на ручку /users/me

### Уровень 2. Планирование изменений

Целевая структура (основные папки и файлы):
```
frontend:
    - package.json      # конфигурация приложения
    - webpack.config.js # remote конфигурация компонент Module Federation
    public/index.html   # html файл react приложения
    src:  # корневое приложение
        - index.js      # запуск react приложения 
        - index.css     # подключение файлов из папки blocks
        components:
            - App.js            # роутинг
            - Main.js           # Основная страница (Монтирование МФ компонент)
            - Footer.js         # Компонент подвала
            - Header.js         # Компонент заголовка
            - ProtectedRoute.js # проверка авторизации для не публичных страниц
        blocks: # css стили для компонент
        images: # иконки
        vendor: # шрифты + нормализация

    auth-microfrontend:     # МФ аутантификации
        - package.json      # конфигурация МФ приложения
        - webpack.config.js # exposes конфигурация компонент Module Federation
        public/index.html   # html файл react приложения
        src:  # МФ приложение
            - index.js      # запуск react приложения 
            - index.css     # подключение файлов из папки blocks
            components:
                - Login.js          # Страница логина
                - Register.js       # Страница регистрации
                - InfoTooltip.js    # Попап статуса регистрации
            blocks:         # css стили для компонент
            images:         # иконки
            vendor:         # шрифты + нормализация    
            utils/auth.js   # методы для работы с api авторизации
    
    places-microfrontend:   # МФ places
        - package.json      # конфигурация МФ приложения
        - webpack.config.js # exposes конфигурация компонент Module Federation
        public/index.html   # html файл react приложения
        src:  # МФ приложение
            - index.js      # запуск react приложения 
            - index.css     # подключение файлов из папки blocks
            components:
                - AddPlacePopup.js      #   Кнопка добавления места   
                - App.js                #   Список карточек
                - Card.js               #   Одна карточка
                - ImagePopup.js         #   Попап просмотра карточки
                - PopupWithForm.js      #   Обертка попапов
            blocks:         # css стили для компонент
            images:         # иконки
            vendor:         # шрифты + нормализация
            utils/api.js    # методы для работы с api
            contexts:       # настройка контекста
    
    profile-microfrontend:  # МФ профайл
        - package.json      # конфигурация МФ приложения
        - webpack.config.js # exposes конфигурация компонент Module Federation
        public/index.html   # html файл react приложения
        src:  # МФ приложение
            - index.js      # запуск react приложения 
            - index.css     # подключение файлов из папки blocks
            components:
                - App.js                # Отображение информации о пользователе
                - EditAvatarPopup.js    # Попап изменения аватара
                - EditProfilePopup.js   # Попап изменения информации о пользователе
                - PopupWithForm.js      # Обертка попапов
            blocks:         # css стили для компонент
            images:         # иконки
            vendor:         # шрифты + нормализация
            utils/api.js    # методы для работы с api
            contexts:       # настройка контекста
```
